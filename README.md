# Northstar POS Dashboard
Functional POS dashboard using HTML/CSS/JavaScript + Express + MySQL.

## Run
1. Run `schema.sql` in MySQL Workbench.
2. Copy `.env.example` to `.env` and set your MySQL password.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000

Includes dashboard KPIs, POS cart, checkout, stock deduction, inventory, sales history and REST API.
